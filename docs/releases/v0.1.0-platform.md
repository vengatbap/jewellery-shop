## 1. Scope & Features
This initial release establishes the foundational security, multi-tenant isolation, and routing gateway controls for the Auric One platform.
* **API Gateway (`apps/api`):** Establishes Express router, rate-limiting, and standard CORS configurations.
* **Authentication Middleware:** Validates JWT authorization tokens, extracts identity payload, and rejects unauthenticated requests.
* **Multi-Tenancy Context Filter:** Intercepts incoming requests, validates `X-Tenant-ID` headers, and assigns organization context.
* **RBAC authorization:** Middleware checks permissions against user roles before routing to business controllers.
* **Audit Logging Wrapper:** Intercepts write transactions to write log parameters (user, branch, action, before/after state) to the audit log database table.

---

## 2. Database Changes & Schemas
Migrates core system schemas:
* `organizations` (tenant metadata)
* `branches` (tenant locations)
* `users` (credentials and profile data)
* `roles` (RBAC mappings)
* `audit_logs` (security write audits)

---

## 3. API Contracts Added
* `POST /api/v1/auth/login` (Auth validation & JWT token generation)
* `POST /api/v1/auth/register` (New tenant sign-up onboarding)
* `GET /health` (Gateway health status check)

---

## 4. Migration & Deployment Notes
* Configure root `.env` variables for PostgreSQL Neon connection credentials.
* Execute `pnpm --filter database db:generate` and `db:migrate` to push schema files.
* Execute `pnpm run dev` to start the Gateway API on port 3000.
