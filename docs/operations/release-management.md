# Auric One ERP v1.0 — Release Management & Maintenance Protocol

## 1. Scope Freeze Policy
Scope for **Auric One ERP v1.0** is **OFFICIALLY FROZEN**.
- No new ERP modules or feature requests will be added to the v1.0 release.
- Feature requests will be triaged for **v1.1 Roadmap**.

## 2. Release Tagging & Patch Strategy
- **v1.0.0 (Release Candidate):** Baseline production launch version (28/28 Gates Passed).
- **v1.0.1 (Hotfix Patch):** Emergency bug fixes for P0/P1 production issues.
- **v1.1.0 (Minor Release):** Feature additions driven by real customer usage feedback.

## 3. Operational Feedback Loop Metrics
During controlled customer pilot launch, track:
1. Time from Signup $\rightarrow$ First Sale ($< 20$ minutes target).
2. Customer setup completion rate.
3. System error rate & security violation alerts.
